# 05. Stack (Pile)

Une **Stack** est une structure de données linéaire qui suit le principe **LIFO** (Last In, First Out).

## 🎯 Concepts Clés
* **Opérations principales** : `push` (ajouter), `pop` (retirer), `peek` (regarder le sommet).
* **Complexité Temporelle** : Toutes les opérations s'exécutent en **O(1)**.
* **Cas d'usage réels** : Gestion de l'historique de navigation (bouton retour), fonction "Annuler" (Ctrl+Z), pile d'appels système (Call Stack).

## 🚀 Commandes d'exécution

```bash
# Python
python python/stack.py

# Langage C
gcc c/stack.c -o stack_test && ./stack_test
```
